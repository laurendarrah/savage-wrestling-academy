Add your website’s restricted test key

The Stripe connection in ChatGPT does not give your website a server API key. Add it here in your owner account; never send it in chat.

  1. Open your Savage account’s Stripe test API keys.
  2. Create a restricted key for “Savage website test”. Confirm you are in test mode. It must begin rk_test_.
  3. Allow reading account details so the website can verify the account. For the upcoming checkout connection, scope permissions to Checkout Sessions (write), Customers (write), Products and Prices (read), Subscriptions (write), Invoices, PaymentIntents and Charges (read), and Customer Portal sessions (write). Leave unrelated permissions off.
  4. Paste the key only into the secure field below and save.

Owner access and authenticator verification are required. Keys are encrypted before storage and are never shown back to you. Live keys are rejected.

Add the restricted live key

The site is in live mode. Purchases listed in CHECKOUT_KINDS charge real cards once this key is saved.

  1. In Stripe, switch the dashboard out of test mode and open live API keys.
  2. Create a restricted key for “Savage website live” with the same permissions as the test key. It must begin rk_live_.
  3. Paste it only into the secure field below.

Stored separately from the test key and encrypted before storage. Never shown back to you.

What happens next?

Checkout remains disabled. After the test key is saved, the remaining work is to connect checkout, verify signed Stripe webhooks, and test payment confirmations, all 12 installments, term expiry, cancellations, and purchase history. No money will move in testing.

Before enabling real payments, review tax requirements and configure Stripe Tax only where you have the required registrations.
