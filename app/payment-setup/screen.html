Connect the academy’s Stripe account

The academy’s Stripe account is yours: you create it and own it, and card payments are paid out to it. The website connects with its own restricted key. Add it here in your owner account; never send it by email or chat.

  1. Create the Stripe account if you don’t have one yet, at dashboard.stripe.com/register, for Savage Wrestling Academy. You can finish the business details later; test mode works straight away.
  2. Create a restricted test key. In Stripe, turn on Test mode and open Developers → API keys. Choose Create restricted key and name it “Savage website test”. It must begin rk_test_.
  3. Give it these permissions: reading account details, so the website can check which account the key belongs to. For online checkout: Checkout Sessions (write), Customers (write), Products and Prices (read), Subscriptions (write), Invoices, PaymentIntents and Charges (read), Balance (read, so card fees reach your books), and Customer Portal sessions (write). Leave everything else off.
  4. Paste it here, only into the secure field below, and choose Verify. The first time, the page shows the name and number of the Stripe account the key belongs to. Check it is the academy’s account, then confirm it. Every later key must come from the same account.

Only the owner can save a key here. Keys are encrypted before they are stored and are never shown back to you. Live keys are refused here.

Connected to the wrong account?

If the academy moves to a different Stripe account, disconnect this one first. Then paste a test key from the other account.

Add the restricted live key

The site is in live mode. Once you save this key, every purchase type that is open for online payment charges real cards.

  1. In Stripe, switch the dashboard out of test mode and open live API keys.
  2. Create a restricted key for “Savage website live” with the same permissions as the test key. It must begin rk_live_ and come from the same Stripe account as the test key.
  3. Paste it only into the secure field below.

Stored separately from the test key and encrypted before storage. Never shown back to you.

Prices

Nothing needs setting up in Stripe for prices. Checkout charges the prices saved in your program settings, including team codes and member discounts, calculated by the website for every purchase. The monthly plan is 12 monthly payments that stop on their own; a year paid upfront is not offered.

What happens next?

Online payment is off. After you save the test key, each purchase type is tried with Stripe test cards before it opens: payment confirmations, all 12 monthly payments, the end of the term, cancellations and purchase history. No real money moves in testing.

Before enabling real payments, review tax requirements and configure Stripe Tax only where you have the required registrations.
